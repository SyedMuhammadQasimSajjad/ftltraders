## ✨ The Vision

**FTL Traders** isn't just a basic static site—it is a high-performance e-commerce engine designed for speed and simplicity. We built a lightning-fast frontend backed by a serverless Cloudflare architecture to bypass heavy setups. The result? Zero latency, seamless WhatsApp ordering, and a frictionless experience for wholesale buyers across Pakistan.

## ⚡ Core Features

<details open>
<summary><b> 🌓 Dynamic Dark/Light Mode</b></summary>
<blockquote>
Client-side theme persistence using Tailwind's <code>.dark</code> class infrastructure and custom toggle rules.
</blockquote>
</details>

<details open>
<summary><b> 📱 Direct WhatsApp Ordering</b></summary>
<blockquote>
Embedded instant-action buttons routing directly to <code>wa.me/923000708221</code>, bypassing the need for complex, high-friction shopping carts.
</blockquote>
</details>

<details open>
<summary><b> 🗺️ Serverless SEO & Sitemapping</b></summary>
<blockquote>
A dedicated Cloudflare Worker automates XML sitemap generation (<code>/sitemap.xml</code>) by querying the active D1 inventory to maximize Google Search visibility.
</blockquote>
</details>

<details open>
<summary><b> 📦 Interactive UI Modals</b></summary>
<blockquote>
Sleek, hidden-by-default modal overlays handling About Us, Contact, Return Policies, and FAQs—all powered by vanilla JS data attributes.
</blockquote>
</details>
